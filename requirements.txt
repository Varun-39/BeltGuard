# Install:  pip install -r requirements.txt
#
# NOTE: torch/torchvision are pinned to the CUDA 12.8 build, which is NOT on
# PyPI. Blackwell GPUs (RTX 50-series, sm_120) require cu128 or newer. Install
# those two FIRST:
# CPU-only machines (or a machine whose CUDA driver can't load these DLLs --
# confirmed on this project 2026-09-12, `import torch` failing on
# c10_cuda.dll) should swap BOTH torch/torchvision below AND onnxruntime-gpu
# for the plain package, installed from the CPU index instead:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#   pip install onnxruntime
# (then reinstall the pinned numpy version below -- the CPU torch install
# pulls its own newer one, which conflicts with roboflow's pin). Training is
# ~20x slower there; inference (vision/service.py) runs on ONNX either way
# and is unaffected.
#
# numpy is pinned deliberately: installing onnxruntime-gpu unpinned pulled a
# second numpy over the top of the first, leaving a half-and-half install that
# broke `import numpy` outright.
#
# No Docker and no WSL required -- the MQTT broker (amqtt) is pure Python.

#   pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
